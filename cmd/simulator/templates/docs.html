API Reference (OpenAPI)

OpenAPI JSON

This page renders the OpenAPI spec shipped with the app. If an endpoint changes, update /openapi.json, the MCP tools, and these docs together.

Base URL: http://localhost:8762
Use this as the root for API requests (e.g. /api/simulators).

MCP (Model Context Protocol)

Agents can control the simulator through the MCP endpoint. This MCP server exposes one tool per HTTP API endpoint plus a generic api_request tool for any path.

Endpoint: /mcp (JSON-RPC 2.0, streamable HTTP)
Discovery: /.well-known/mcp
Base URL: http://localhost:8762

The base URL is the origin of the app window. In desktop mode it is typically http://localhost:8762. In Docker/server mode it is usually http://localhost (or your host IP).

Initialize

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {}
}

List Tools

{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/list",
  "params": {}
}

Call a Tool

{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "simulators.list",
    "arguments": {}
  }
}

Streamable HTTP (SSE)

Set Accept: text/event-stream or append ?stream=true to get SSE responses.

curl -N -H "Accept: text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":4,"method":"tools/list"}' \
  http://localhost:8762/mcp

Generic API Tool

{
  "jsonrpc": "2.0",
  "id": 5,
  "method": "tools/call",
  "params": {
    "name": "api_request",
    "arguments": {
      "method": "POST",
      "path": "/api/simulators",
      "body": { "type": "inverter" }
    }
  }
}
